Sobre a Simulação de CDB

Certificado de Depósito Bancário pós-fixado

O CDB é um título de renda fixa emitido por instituições financeiras para captação de recursos. Nesta simulação, os juros são acumulados mensalmente sobre o saldo do mês anterior (juros compostos), incidindo Imposto de Renda regressivo apenas sobre o lucro obtido.
